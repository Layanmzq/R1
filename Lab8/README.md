## K-Nearest Neighbors (KNN) Assignment
# Description

In this assignment, the K-Nearest Neighbors (KNN) algorithm was implemented to classify data using the provided dataset KNN_Project_Data.

Steps
Loaded and explored the dataset
Standardized the features using StandardScaler
Split the data into training and testing sets
Trained the KNN model
Evaluated the model using confusion matrix and classification report
Determined the optimal value of K using the error rate plot
Conclusion

The KNN model was successfully built and evaluated, and the optimal K value was selected to improve model performance.

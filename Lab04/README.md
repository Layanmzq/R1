# Lab 4: Data Quality Assessment & Preprocessing

## Overview

In this lab, data preprocessing techniques were applied using the Titanic dataset. The goal was to improve data quality before analysis.

## Tasks

* Checked data types
* Detected missing values
* Introduced artificial missing values
* Removed records with missing values
* Detected outliers using IQR
* Applied normalization (Min-Max and Z-score)
* Applied PCA

## Dataset

The Titanic dataset was used in this lab, and it is **attached with the submission**.

## Note

All steps were implemented using Python and Jupyter Notebook.

# Credit Card Customer Segmentation

This lab applies **K-Means Clustering** to segment credit card customers based on their behavior and spending patterns.

## Project Overview

The notebook includes:

- Loading the credit card customer dataset
- Exploring and cleaning the data
- Handling missing values
- Scaling the features
- Applying K-Means clustering
- Using the Elbow Method
- Visualizing customer segments

## Files Included

- `Credit_Card_Customer_Segmentation_EMBEDDED_NO_ERRORS.ipynb` — completed notebook
- `CC_GENERAL.csv` — attached dataset used in the lab
- `README.md` — project description

## Dataset

The dataset `CC_GENERAL.csv` is included with this project. It contains credit card customer information such as balance, purchases, cash advances, credit limit, payments, and customer usage behavior.

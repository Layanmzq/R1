# E-Commerce Customers Linear Regression Project

In this project, the Ecommerce Customers dataset was analyzed using Linear Regression.
The data was explored, cleaned, and prepared for modeling by selecting relevant numerical features.

A Linear Regression model was trained to predict the Yearly Amount Spent by customers.
The model performance was evaluated using standard metrics such as MAE, MSE, RMSE, and R².

# Final Conclusion

In this analysis, the Ecommerce Customers dataset was successfully explored and prepared for modeling.
A Linear Regression model was trained to predict the Yearly Amount Spent based on customer behavior features.

The model showed good performance in predicting customer spending.
The analysis indicated that Length of Membership is the most significant factor influencing yearly spending, suggesting that long-term customers tend to spend more.

Overall, the results demonstrate that customer engagement and membership duration play an important role in determining customer value.

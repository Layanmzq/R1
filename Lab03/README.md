## Amazon Sales Dataset – EDA

This project performs exploratory data analysis (EDA) on an Amazon sales dataset to understand sales patterns, product performance, and revenue trends. The analysis includes basic data cleaning, checking data types and missing values, and creating visualizations to explore distributions, relationships between variables, and monthly revenue trends.

### Dataset
The dataset used in this project is available on Kaggle:  
https://www.kaggle.com/datasets/aliiihussain/amazon-sales-dataset?resource=download

Due to GitHub file size limitations, the dataset file is not uploaded directly to this repository. Please download the dataset from the link above and place it in the same folder as the notebook before running the code.
